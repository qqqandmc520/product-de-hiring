# 模式三：面试后评估

## 从原始材料重新建立证据

先继承并核对 `role-boundary.md`：本岗位是产品主导、业务主导、复合还是尚不明确，产品是否为招聘核心、必要业务知识和专业责任由谁承担。新材料与画像冲突时显式标出，不按候选人的强项倒改岗位属性。业务主导岗位的专业适配超出本模型；可继续整理证据，但不能认证业务专家资格。

1. 按 `intake.md` 核对岗位依据及包含具体回答的实际问答记录；简历、计划和作品有则一并读，缺简历不阻碍评估已观察回答。核对候选人和面试轮次，保留来源完整性；有旧评价时先提取原始证据，再对照旧判断，避免继承偏见。只有结论性评语时先补原始问答，不据此判断能力。
2. 区分候选人与面试官、事实与摘要评价，标时间/段落。对影响去留的片段阅读前后文：是否未给事实、是否追问过、是否提供了解法、是否中断了回答。
3. 更新证据记录。历史自述、现场推演、作品和数据分别记录；同一项目规划与上线结果不得混用。
4. 先做实际覆盖表，再按七项评估。P3/P7没给具体产物走查机会时，即使交流顺畅/不顺畅，也不能据此评其产品语义或感知体验能力。
5. 单独检查岗位额外职责与条件。强证据不能掩盖另一项关键岗位不匹配；同样不能因未观察就给否定判断。

按 `role-priorities.md` 逐条继承同版H:要求与最低表现。先写核心要求证据及影响，再看其他必需、可培养和加分；不能面后发现某人弱项才把它升级成核心。若旧画像没有分层，依据原职责提炼暂定解释并披露；会改变建议的歧义须澄清或给受限结论，不伪称标准事先已确定。

## 输出结构

开头直接写：**针对哪个岗位版本，建议继续/先补证/当前不建议继续；最关键的2–3条理由；结论限于什么材料和范围。** 紧接着用简短结论明确三件事：①本次是否为产品能力主导的招聘及依据；②候选人本轮呈现的是哪些产品判断、领域知识与经营协同证据；③产品核心、必要业务知识及其他职责分别是否支持岗位要求。不能仅列七项表而不回答产品岗位适配，也不能把“推荐补面”写成已达到岗位标准。

随后依次提供：

| 区块 | 必须回答 |
| --- | --- |
| 实际覆盖 | 哪些任务被问到、追问多深、哪些未问/纪要缺失？是否有明显提示？ |
| 要求分层与决策影响 | 每条核心/相关其他必需的最低表现、支持与反证、状态、实际机会、对本阶段建议的影响；可培养的资源/节点是否成立，加分有何额外价值？ |
| 产品岗位适配 | 岗位为何以产品能力为核心？候选人哪些亲自判断/作品支持这一核心，哪些只是专业知识或业务业绩？尚缺什么？ |
| 七项能力 | 每项状态、原始证据ID与位置、判断解释、相反证据、未知及岗位影响 |
| 必要业务知识 | 需要理解到哪里、何处需来源专家判断？知识与转译分别有什么证据，是否为入职即需、可培养或加分？ |
| 其他岗位责任 | 指标定义、基线/周期、个人贡献和核验状态；交付、经营、管理与协同的具体证据 |
| 去留依据 | 哪些是关键不匹配，哪些仅是补证；为何足以/不足以支持下一步 |
| 最小下一步 | 只补会改变决策的事项，给时长、任务和希望新增的证据；明确无法由本次纪要判断的部分 |

使用“在该题及追问中未说明……，对本岗位的……构成风险”而非“没有能力/思维不行”。不将态度、表达风格、对组织的抱怨直接转化成能力判断；如涉及协作，只评具体决策、行为与结果。

明确指出哪些已观察缺口足以改变建议，哪些只是未知或低优先级差距。加分缺失不淘汰，强加分不补偿核心/必需的实质缺口；可培养项不按入职即需处理，但缺乏现实补齐条件时应说明风险并核对画像，不能承诺自然补齐。核心未知不等于否定，也不自动推进：按阶段、已有相关证据及最小验证成本解释建议，不能计数通过。

对同一表现可能有两种解释时，给区分办法。例如，遗漏恢复过程可能是能力缺口，也可能是面试一直只问成功路径；核对实际追问后再定状态。反对面试官方案不是负面证据，应看其替代方案是否满足同一用户目标和约束。

本岗既定关键产品表现存在明确缺口时，行业知识、营收、增长或团队规模不能抵消；必要行业知识存在已观察且关键的缺口时，产品强项同样不能自动抵消。知识缺口、产品化缺口和未给专业事实三者分开。没有充分产品观察机会时，写“当前不足以确认符合产品核心要求”，不写“候选人属于业务专家所以不合适”。

用户问“仅按当前材料是否推荐”时，沿用同一标准清楚回答当前支持程度和阶段建议。可建议验证性补面，但须明确已有证据是否支持推进；若已有充分关键不匹配，不用无限补证回避不推荐。只改变决策情境而未新增证据，不悄悄将原来的匹配结论翻转，须说明此前推荐的阶段与本次约束差异。

## 比较与接续

比较候选人时，先保证岗位画像版本、核心场景事实及观察机会可比。对“某候选人讲得更多”与“某候选人确有更强证据”分开；不同项目不机械比较业务指标或团队规模；这些内容是否需要评估由本岗决定。

记录结论与日期，不覆盖原轮次。补面后把新证据与原缺口对应，说明哪些判断改变、哪些未变。若下一轮岗位要求变化，明确新画像下需要重看哪些证据，不追溯改写原面试表现。

给JD修订的反馈要脱离个人标签，记录：岗位原要求是否清晰、面试机会是否充分、实际反复出现的关键差距、当前样本限制。不能把某个人的弱项直接升级为新的通用硬门槛。
