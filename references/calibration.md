# 跨部门校准与虚构练习

以下均为招聘应用建议和虚构材料，不是能力模型正式案例，也不是真实候选人。

## 推广方式

先选择一到两个有实际招聘需求的部门试用，各自确定岗位画像。用同一份已授权脱敏的简历、纪要和作品，至少两位评估者先独立记录证据与状态，再对齐。若只有一位评估者，先自检，不能宣称评估者间一致。

记录分歧：能力归属、观察状态、证据引用、岗位要求或最终建议。对齐不是强迫结论相同，而是让相同事实使用相同定义、避免漏证与误判；对于真实取舍保留异议和补证方案。

建议同时看：来源定位是否可复查；未观察项被误判比例；同一关键证据被不同理解的原因；关键岗位要求是否漏评；去留建议分歧能否由补证解释。样本量与观察窗口预先约定，不把某个一致率设为本技能强制通过线。

模型版本、技能版本、岗位画像版本分别管理。新JD和标准只对约定轮次生效；已评候选人若需要重新比较，显式重评并保留原记录。技能变更应由具体失败案例支持，再用正反案例复查。

## 四环节练习：非AI的企业采购审批产品

岗位：内部采购审批产品负责人。用户是偶尔提交采购的员工及审批人；目标是提交正确材料、理解进展、在变更和失败后继续完成。现阶段重点P1/P5/P6，其他项仍需观察。额外职责是跨团队交付；没有DAU增长、OTA或AI硬要求。

### 简历片段

候选人C-A：负责审批改版，声称退回率从18%降至10%；负责梳理表单、规则及上线走查。未写样本量与口径。简历没有感知体验案例。

应用预期：有值得初试的线索；数字仍为自述，需核实基线/周期/个人贡献。P7未展示是unobserved，不是gap；不能因缺AI经历拒绝。

### 面试事实卡

员工提交一项采购。金额超过阈值需追加审批，发票可稍后补交；提交后可能离开；部分附件可能上传失败。领域阈值由公司制度给定，候选人不必猜。考察用户是否知道已生效范围、未完成事项和后续动作，允许不同界面与机制。

应用预期：使用真实案例走查加场景迁移，计时总计60分钟；为P3/P7安排具体产物观察机会，独立交付要求单独问。问法中不直接给“必须添加确认框”的答案。

### 纪要片段（虚构，材料仅此）

- 12:10，候选人：“采购单号不随补附件改变；补附件不重建采购单，金额改变则按规则判断是否重审。”这是现场假设推演，未证实实际落地。
- 18:20，面试官：“加个确认框再恢复不就好了？”候选人：“对。”
- 21:00，候选人：“上传完就是提交完成。”面试官中性澄清“现在一份附件成功、一份失败”，候选人仍表示所有材料都显示已完成，但未解释这种事实冲突。
- 纪要没有讨论离开回来，没有作品截图、文字走查，也没有交付案例。

应用预期：P1有具体推理支持但范围有限；18:20不能当作独立P5恢复能力。21:00可构成P5结果确认方面的具体缺口，并关联P1事实一致性；不要把一段话扩张成七项皆弱。P6/P3/P7及交付职责未充分观察。若P5问题在本岗位是明确关键不匹配，可据此提出当前不建议，且保留未知；如果关键条件/追问仍不清楚则先补证。不存在凭状态数目计算的唯一去留答案。

### JD反馈

应用预期：建议将结果确认、部分失败及用户继续任务的责任说具体；P7缺材料先改面试覆盖；保留交付要求。不能加“必须做过AI/OTA/DAU增长”，不能据一个案例推断所有产品候选人普遍不懂体验。

## 额外反例

- 增长负责人简历有大量营收数据：可以是业务线索，不能直接支持七项产品能力或DAU因果。
- 候选人主张模型动态判断而非固定if/else：检验事实边界、用户控制、质量与恢复，不因技术路径不同直接判错。
- 候选人未提供旅行专业事实：可请求澄清、接受明确假设，不能把编造精确行程当产品能力。
- 面试计划覆盖七项而纪要只问三项：按实际材料评三项，其余标未知。
- 旧材料给过否定结论、新材料补足关键证据：允许结论变化，说明证据及岗位版本，不能维护历史答案。

## v0.2首次输入引导的情景校准

以下检查任务路由与材料依赖；没有实际候选人结论，不替代独立用户实测。

| 初始输入 | 合理动作 | 应避免的行为 |
| --- | --- | --- |
| 只说“使用技能” | 询问当前环节，介绍JD可由岗位简述替代，之后按需接收材料 | 一次索要JD、全部简历、全部纪要和七项权重 |
| 已给JD＋简历，要筛选 | 直接读材料、建画像草案并筛选 | 重问做哪个环节、要求用户重传、等完整画像确认才开始 |
| 只有简历，问岗位适配但没有岗位信息 | 先提取履历线索，补问岗位依据 | 根据候选人履历自行倒推岗位，再给去留 |
| 没有正式JD，但已清楚说明用户、任务及责任，要准备面试 | 用岗位简述建草案；有候选人依据则做专属提纲，否则做通用提纲 | 把正式JD作为所有输出的必要条件 |
| 岗位依据＋实际面试问答，没有简历 | 评估已观察回答，列明材料范围 | 因缺简历完全拒绝面后评估，或假装有履历佐证 |
| 岗位依据＋一句“感觉不够深” | 补关键原始问答，可先整理评估重点 | 将面试官评价当作已观察缺口 |
| 只有岗位背景，想写JD | 起草JD并说明无旧稿/招聘反馈 | 索要候选人简历，虚构原文对照和面试归因 |
| 已存岗位画像，新增一份简历 | 复用画像，核对文件归属后筛新增人选 | 要求整套重新填写，或未经请求重评全部人选 |
| 材料无法读取或不知归属哪位候选人 | 说明具体缺失或归属问题，补问并继续无依赖工作 | 以未读取的内容作判断，错配证据，因输出格式未选而暂停 |
