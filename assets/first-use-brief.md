# 首次使用：可选输入便笺

可以直接对话，不必逐项填表，也不必理解七项能力。材料可以粘贴、作为附件提供，或说明所在文件/目录；已经提供过的内容不用重复。

- 我现在想做：筛简历 / 准备面试 / 面后评估 / 优化JD。
- 岗位依据：已有JD或岗位画像在……；没有的话，产品是……，给……用户使用，这个人主要负责……。
- 本环节材料：
  - 筛简历：候选人简历或履历材料在……。
  - 准备面试：候选人简历/项目/已有记录在……；若只需岗位通用提纲可直接说明。
  - 面后评估：实际问答纪要/转写在……；只有结论性评价时请补关键问答。
  - JD修订：现行JD在……；没有旧稿可以根据岗位背景新写。招聘反馈有则提供。
- 有则补充：当前最关键的问题、明确岗位条件、面试轮次/时长、已有结论及希望本次核实什么。
- 输出偏好：可不填；默认可读文档，面试默认60分钟。

最短示例：“使用 $product-de-hiring，帮我筛选这几份简历，岗位JD和简历都在这个目录。”
